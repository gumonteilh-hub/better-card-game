# 💡 Better Card Game - Propositions de Game Design

Bienvenue dans le dossier d'idées pour le système de synergies Race × Classe !

## 📚 Table des Matières

### 🏁 Introduction
Ce dossier contient des propositions détaillées de game design pour créer des **synergies croisées** entre :
- **3 Races** : Human, Dragon, Demon
- **3 Classes** : Warrior, Mage, Rogue

**Objectif** : Permettre de construire un deck autour d'une Race OU d'une Classe, avec des synergies cohérentes et thématiques.

## 📖 Documents par Catégorie

### 🎭 Propositions par Race

#### 1️⃣ [race-human.md](race-human.md) - HUMAN (Humain)
**Thème** : Armée coordonnée, force du nombre, tactique militaire

**4 Propositions principales :**
- **L'Armée Coordonnée** : Formation, Ralliement, Nombre Critique
- **Tactique Militaire** : Ligne de Front, Redéploiement, Flanc
- **L'Unité fait la Force** : Jumelé, Escouade, Sacrifice Coordonné
- **Héritage & Tradition** : En Mémoire, Vétéran, Héritage

**Mécaniques signatures** :
- 🎖️ **Formation** : Bonus selon les alliés adjacents
- 👥 **Nombre Critique** : Seuils de puissance (4, 5, 7+ alliés)
- 🤝 **Ralliement** : Buff quand un allié entre en jeu
- 💪 **Escouade** : Groupe de créatures qui partagent des buffs

---

#### 2️⃣ [race-dragon.md](race-dragon.md) - DRAGON (Dragon)
**Thème** : Puissance solitaire, maîtrise élémentaire, accumulation de richesses

**4 Propositions principales :**
- **Maîtres des Éléments** : Feu, Glace, Foudre, Terre, Vent
- **Gardiens de Trésors** : Accumulation et dépense de Trésors
- **Puissance Solitaire Ultime** : Solitaire I/II/III, Domination, Orgueil
- **Cycles de Vie Draconiques** : Évolution (Œuf → Dragonnet → Dragon → Ancien)

**Mécaniques signatures** :
- 🐲 **Solitaire** : Bonus massifs quand seul
- 🔥 **Souffle Élémentaire** : Attaques spéciales par élément
- 💎 **Thésaurisation** : Accumulation de Trésors
- 🌟 **Évolution** : Transformation progressive en créature légendaire
- 👑 **Domination** : Bonus si plus puissant que tous les autres

---

#### 3️⃣ [race-demon.md](race-demon.md) - DEMON (Démon)
**Thème** : Peur, corruption, sacrifice, pactes interdits

**4 Propositions principales :**
- **Seigneurs de la Peur** : Peur, Terreur, Cauchemar, Démoniaque
- **Pactes Démoniaques** : Pacte, Prix du Sang, Damnation
- **Corruption et Contagion** : Corruption, Contagion, Possession, Souillure
- **Sacrifice et Renaissance** : Rituel, Offrande, Renaissance Démoniaque

**Mécaniques signatures** :
- 😱 **Peur** : Debuff sur les ennemis (-1/-1 par point)
- 🩸 **Pacte** : Buff puissant contre sacrifice continu
- 🖤 **Corruption** : Debuff progressif qui peut retourner les créatures
- ⚰️ **Rituel** : Sacrifice d'alliés pour effets massifs
- 🔥 **Renaissance** : Résurrection améliorée
- ⚠️ **Damnation** : Risque de défaite si mal géré

- ☠️ **Poison** : Dégâts over time
- 💰 **Vol** : Steal resources

## 🎨 Philosophie de Design

### Principes Clés

#### 1. **Cohérence Thématique**
Chaque mécanique doit **faire sens** avec le nom de la Race/Classe.
- Human = Armée → Formation, Nombre Critique ✅
- Dragon = Solitaire → Domination, Orgueil ✅
- Demon = Peur → Terreur, Cauchemar ✅

#### 2. **Synergies Croisées**
- Les cartes **Human** synergisent entre elles (quelle que soit la classe)
- Les cartes **Warrior** synergisent entre elles (quelle que soit la race)
- Mais **Human Warrior** a une identité unique

#### 3. **Asymétrie**
Chaque combinaison se joue différemment :
- Human Warrior (tank de groupe) ≠ Dragon Warrior (tank solo) ≠ Demon Warrior (tank suicidaire)

#### 4. **Profondeur**
Chaque mécanique offre de la **profondeur stratégique** :
- Armure : Quand accumuler vs dépenser ?
- Combo : Quelle séquence optimale ?
- Solitaire : Quand sacrifier les alliés ?

## 💭 Notes et Considérations

### Équilibrage
- Les mécaniques sont **volontairement puissantes** dans ces propositions
- Il faudra ajuster les nombres en pratique (coûts, stats, seuils)
- Principe : mieux vaut commencer fort et nerfer que l'inverse

### Compatibilité avec l'Existant
- Toutes les mécaniques sont **compatibles** avec le système actuel
- Utilisent les triggers existants (on_play, on_attack, on_death, on_alone, on_surrounded)
- Peuvent nécessiter de nouveaux `Effect` et `Action` types

### Extensions Futures
- Le système est **extensible** : nouvelles races/classes peuvent s'ajouter
- Possibilité de "multi-classe" dans le futur ?
- Possibilité de races hybrides (Dragon-Demon) ?
